# Data Structures and Algorithms II (DSA-II)

This repository contains my implementations and solutions for the **DSA-II** course. The focus is on advanced algorithmic paradigms and graph theory.

---

## 📂 Topics Covered

### 1. Recursion
Solutions to problems that solve a base case and then call themselves with a smaller version of the problem.
* **Key Example:** The Climbing Stairs problem ($f(n) = f(n-1) + f(n-2)$).

### 2. Divide and Conquer
A strategy that breaks a problem into smaller sub-problems, solves them independently, and combines their results.
* **Key Topics:** Max-Min Problem, Maximum Sum Subarray.

### 3. Greedy Algorithms
Algorithms that make the "locally optimal" choice at each step with the hope of finding a global optimum. 
* **Key Topics:** Activity Selection, Huffman Coding (Compression), and Fractional Knapsack.

### 4. Dynamic Programming (DP)
Similar to Divide and Conquer, but used when sub-problems overlap. It stores the results of sub-problems to avoid redundant work.
* **Key Topics:** Coin Change Problem, 0/1 Knapsack Problem.

### 5. Disjoint Set Union (DSU)
A data structure that tracks elements partitioned into non-overlapping sets. It is highly efficient for connectivity problems.
* **Key Topics:** Union-Find operations, Path Compression.

### 6. Graph Algorithms & Shortest Path
Techniques for finding the most efficient way to travel between nodes in a network.
* **Key Topics:** * **MST:** Kruskal’s and Prim’s Algorithms.
  * **Shortest Path:** Dijkstra’s (Non-negative weights) and Bellman-Ford (Handles negative weights).
